## DETECCIÓN DE PACKS
================================================================================

Lógica actual (catalogo.html L739, L787):
  isPack = item.items_incluidos && 
           Array.isArray(item.items_incluidos) && 
           item.items_incluidos.length > 1

⚠️ PROBLEMA 1: items_incluidos es array de STRINGS, no objetos
  - No incluye duración, precio o espacio por item
  - No se puede secuenciar un pack multi-fase (ej: Panacea → Masaje → Restaurante)

⚠️ PROBLEMA 2: No existe campo "modalidad"
  - No se distingue entre:
    * Individual (1 persona, 1 terapeuta)
    * Pareja (2 personas, 1 o 2 terapeutas según servicio)
    * Mixto (fases con espacios diferentes)

⚠️ PROBLEMA 3: Campo "terapeutas_requeridos" no existe
  - Suite Privada: 1 terapeuta para 2 personas
  - Masaje Pareja: 2 terapeutas para 2 personas
  - No hay forma de distinguir esto actualmente

## CAMPOS FALTANTES PARA MODELO OPERATIVO
================================================================================

1. modalidad: string enum
   - "individual" (1 pax, 1 terapeuta)
   - "pareja" (2 pax, 1-2 terapeutas según servicio)
   - "mixto" (pack con múltiples fases y espacios)

2. terapeutas_requeridos: number | "auto"
   - 0: No requiere terapeuta (ej: Circuito Spa)
   - 1: Requiere 1 terapeuta (ej: Masaje Individual, Suite)
   - 2: Requiere 2 terapeutas (ej: Masaje Pareja)
   - "auto": Calcular según pax y categoría

3. requires_therapist: boolean
   - true: Necesita asignación de terapeuta
   - false: Autoservicio (Circuito Spa, Gimnasio)

4. secuencia: object[] (para packs mixtos)
   Estructura propuesta:
   [
     { item: "Circuito Spa", espacio: "spa", duracion: 90, orden: 1 },
     { item: "Masaje Pareja", espacio: "cabina1", duracion: 50, orden: 2 },
     { item: "Menú Restaurante", espacio: "restaurante", duracion: 60, orden: 3 }
   ]

## INCONSISTENCIAS DETECTADAS
================================================================================

1. items_incluidos no tiene precios
   - Al desglosar un pack, no se sabe el precio de cada item
   - Impide cálculo de precio prorrateado

2. espacio vs allowedSpaces
   - "espacio" es legacy (string único)
   - "allowedSpaces" es nuevo (array multi-select)
   - Ambos coexisten, puede haber inconsistencia

3. pax limitado a 1/2/group
   - "group" no tiene número concreto
   - No se puede calcular terapeutas para grupo

4. sesiones no se guarda por item en packs
   - Un pack "5 Masajes + 2 Faciales" no puede representarse
