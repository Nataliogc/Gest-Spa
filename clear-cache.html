🔧 Limpiar Cache de la Aplicación

Si estás experimentando problemas después de una actualización, limpia el cache del navegador y el Service Worker.

Pasos Manuales Alternativos:

  • Chrome/Edge: Ctrl + Shift + Delete → Borrar datos de navegación
  • Desregistrar SW: F12 → Application → Service Workers → Unregister
  • Refrescar: Ctrl + F5 (refresco forzado)
