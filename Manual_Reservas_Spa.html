Manual de Reservas

Circuito Spa (Recepción) • Versión 1.0 • Enero 2026

OBJETIVO: Este manual detalla el paso a paso exclusivo para que el personal de recepción gestione reservas de Circuito Spa mediante el sistema Zenith, garantizando la correcta aplicación de tarifas según el origen del cliente.

1. Acceso a la Agenda

Selecciona "Spa" en el panel de gestión para visualizar los turnos disponibles.

Identifica el turno deseado y verifica que queden plazas disponibles.

2. Escenario A — Hotel Incluido

Para clientes con el Spa incluido en su tarifa de habitación.

  1. Haz clic en "Añadir Reserva" dentro del turno elegido.
  2. Introduce los datos del cliente (Nombre y Teléfono).
  3. Selecciona el origen Hotel - Incluido.
  4. Verifica que el sistema marque el total como 0.00 €.

Nota: El control de pago se gestionará automáticamente sin deuda.

3. Escenario B — Hotel No Incluido

Para clientes alojados que deben abonar el circuito a precio preferente.

  1. Sigue los mismos pasos iniciales de apertura de formulario.
  2. Selecciona el origen Hotel - NO Incluidos.
  3. El sistema aplicará el Precio Automático configurado.
  4. Observa en el "Control de Pago" la deuda pendiente para proceder al cobro.
REGLAS DE ORO (BLOQUE CRÍTICO)
  • Sin Terapeutas: El Circuito Spa no utiliza personal directo. No asocies terapeutas.
  • Aforo Automático: El sistema controla el límite de 20 plazas. Respeta los bloqueos.
  • Precios Automáticos: Nunca introduzcas el precio manual. Todo depende del "Origen" seleccionado.
  • Alojados sin Spa: No uses "Particular" para clientes del hotel; usa siempre "Hotel - NO Incluidos".

Errores Comunes

¿No aparece "Circuito Spa" en el selector?
Comprueba que estás en el menú principal de "Spa" y no en "Cabinas".
¿Qué pasa si el aforo está completo?
El sistema no permitirá guardar. Ofrece al cliente el siguiente turno disponible con plazas.
