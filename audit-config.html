4. Configuración del Planning

4.1 Horarios por Día

Día Slots

4.2 Reglas de Disponibilidad

  • Slots pasados se filtran automáticamente (fecha actual)
  • Reservas existentes se excluyen del cálculo
  • Se preserva el slot original al editar
  • Módulos Timeline: slots cada 15 min (10:00-22:00)

4.3 Días Cerrados

  • Formato: { date: "YYYY-MM-DD", reason: "Motivo" }
  • Verificación de reservas antes de cerrar
  • Bloquean todas las reservas del día

5. Cálculo Económico

5.1 Fórmula de Cálculo

Total = (PAX × Precio/PAX) + Σ Extras

5.2 Selección de Precio (Módulo SPA)

Paso Acción
1 Si origen = particular o hotel_no_inc → Calcular día
2 Si V/S/D → Usar precio fin de semana
3 Si L/M/X/J → Usar precio entre semana
4 Si otro origen → Precio = 0€

5.3 Casos que Provocan Total = 0€

Escenario Razón
Origen sin pago hotel_inc, bono, etc.
Sin servicio seleccionado !svcName
Servicio no en catálogo !serviceData (módulo ≠ SPA)
PAX = 0 Cálculo 0 × precio
